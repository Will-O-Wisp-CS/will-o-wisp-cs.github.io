# 大会告知画像の生成（クラウドの Claude から）設計

## 目的と理由

鬼火CS の大会ごとの告知画像（X 投稿用、1200×675）を、主催者がスマホの Claude アプリ（Claude Code のクラウドセッション）から「11月の告知画像作って」と頼むだけで作れるようにする。

これまでは PC 上の Claude に頼んで作っていたが、作り方（スクリプト・ひな形・背景画像）がリポジトリにも手元にも残っていなかった。PC がなくても、外出先でさっと作れるようにしたい。

## ゴール

- 月（または大会1件）を指定すると、その月の大会ごとに告知画像 PNG ができる
- 見た目は今の画像（`output/11月イベント画像/*.png`）と同じ
  - 背景はキービジュアル。下の方は黒へのグラデーション
  - 左下に、大きな日付「11/29」、曜日の四角、「受付 12:00~」、「鬼火CS in ○○」
- 必要なものはすべて git に入っていて、クラウドの環境で `npm ci` の後にそのまま動く
- できた画像はスマホで開ける URL で受け取れる

## 作らないもの

- 会場の告知画像（1200×1500。概要・賞品・住所入り）
- Web ページ（`/announce/` のような画面）
- 受付ポスター（`output/デッキリスト提出ポスター/`）

## 失敗とみなすこと

- クラウドで動かない（ブラウザや OS のフォントに頼る、手元にしかないファイルを使う）
- 画像の受け取りのために `main` にコミットされる、または `main` へのマージが必要になる
- 文字化け・豆腐（フォントにない字）

## 前提・制約

- 大会データは `src/shared/events.json` と `src/shared/events-archive.json` を `mergeEventLists` で合わせたもの。承認「◎」のものだけが入っている
- 受付時刻は開始の20分前（`src/schedule/schedule.ts` の `RECEPTION_MINUTES_BEFORE`）
- 曜日の四角の色は、スケジュールのマーカーと同じ（土＝青、日＝赤、祝日＝黄、平日＝なし。祝日を優先）。祝日は `calendar.ts` で計算する
- 機能フォルダ同士は import しない。`calendar.ts` と受付時刻の計算を共用するなら `shared/` に移す
- ルート直下にフォルダを増やさない
- Node で型を取り除いて直接実行するので、スクリプトから import されるファイルの import は `.ts` 拡張子付き
- 背景画像の元ファイルは 1655×988 の JPEG（白地、ロゴ「鬼火CS」入り）

## 作り方の候補

1. **SVG のひな形を Node で PNG にする（採用）** — `@resvg/resvg-js` を使い、フォントファイルを読み込んで描く。ブラウザがいらないので、クラウドでも確実に動く。dev 依存が1つ増える
2. HTML のひな形をヘッドレス Chrome で撮る — 受付ポスターと同じ方法。クラウドに Chromium を入れる必要があり、重くて壊れやすい
3. ブラウザ上の画像メーカー（Web ページ）— 主催者が「Claude 経由で作れればよい」としたので不要

## 決まったこと

- 使う場所はクラウド（スマホの Claude アプリで、このリポジトリを開いたセッション）
- 対象は大会ごとの画像（1200×675）だけ
- 背景画像はリポジトリに入れる（公開リポジトリなので誰でも見られる。主催者が了承済み）

## 構成（Claude の判断）

```
src/announce/
  assets/key-visual.jpg      背景（元ファイル S__127262729.jpg）
  assets/fonts/*             OFL など再配布してよいフォント（日本語の太字、日付用の縦長の数字）
  announce.ts                大会 → 画像に載せる文字（日付 '11/29'、曜日、曜日の色、受付 '12:00~'、'鬼火CS in ○○'）の純粋関数
  announce.test.ts
  template.ts                文字 → SVG 文字列（純粋関数。背景は data URI か href で渡す）
  template.test.ts
  render.ts                  Node 専用。月・大会の指定 → PNG を書き出す（npm run announce）
.claude/skills/cs-announce-image/SKILL.md   クラウドの Claude 用の手順
```

- コマンド: `npm run announce -- 2026-11`（その月の、これから開催する大会すべて）。`--date 2026-11-29` や `--venue` で絞り込み、`--reception 12:10` で受付時刻を上書きできる
- 出力先: `src/announce/out/<YYYY-MM>/<YYYY-MM-DD>_<HHMM>_<開催地>.png`（今のファイル名と同じ形。`HHMM` は開始時刻）。`out/` は `.gitignore` に入れる
- 受け渡し: スキルは、作った PNG を `git add -f` でセッションの作業ブランチ（クラウドが用意する `claude/...`。`main` ではない）にコミット・push する。そのあと `https://raw.githubusercontent.com/Will-O-Wisp-CS/will-o-wisp-cs.github.io/<ブランチ>/...` のリンクをチャットに出す。そのブランチはマージしない
- `vite.config.ts` の input には入れない（ページではない）。`src/announce/` は Vite の root の下にあるが、どこからも参照しないのでビルドには入らない
- CLAUDE.md のフォルダ構成とドメインルールに追記する

## 作る人に任せること

- フォントの具体的な選定（今の画像に近い太さ・縦長さで、日本語の開催地名がすべて出るもの）と、サブセット化するかどうか
- 文字の位置・大きさの微調整（今の PNG と並べて見比べる）
- 背景の縮小・トリミングとグラデーションの具体的な値
- `--venue` などの細かいオプションの形
