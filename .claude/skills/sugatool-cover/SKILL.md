# スガツール カバー画像

スガツールのイベントに付けるカバー画像を、決まったデザインで作る。デザインは毎回同じ。**新しいデザインを考えたり、HTML を一から書いたりしない。** このスクリプトだけを使う。

- 背景: `background.png`（文字なしの「ONIBI CHAMPIONSHIP」のイラスト。1200×675）
- 文字: 左下に `11/29`・曜日のバッジ・`受付 12:00~`、その下に `鬼火CS in ○○`。白文字（Noto Sans JP）
- 曜日のバッジ: 土＝青 / 日・祝日＝赤 / 平日＝灰（祝日は `src/shared/calendar.ts`）
- 受付＝開始の20分前。開催地・開始時刻は `src/shared/events.json` と `events-archive.json` から取る

## 手順

1. **日付を決める。** 「明日」「今週の土曜」などは JST の今日から具体的な日付にする。指定がなければ明日。
2. **実行する。** リポジトリのルートで:
   ```bash
   node .claude/skills/sugatool-cover/cover.ts 2026-11-29 <出力フォルダ>
   ```
   - 日付を省くと JST の明日。その日の開催を1件1枚、`鬼火CS_YYYY-MM-DD_開催地.png` で書き出す
   - 出力フォルダはリポジトリの外（指定がなければダウンロードフォルダ。クラウドならスクラッチパッド）
   - `npm install` 済みであること（フォントは `@fontsource/noto-sans-jp`、描画は playwright）
   - Chromium の版が合わずに起動できないときは `CHROMIUM_PATH` に Chrome の実行ファイルを指定する（例: `/opt/pw-browsers/chromium-*/chrome-linux64/chrome`）
3. **画像を見て確かめてから渡す。** 文字のはみ出し・背景の崩れがないか自分で開いて見る。ファイルを渡す手段があれば送る。
4. その日の開催が見つからないときは、events.json がまだ更新されていない可能性を伝える。

## デザインを変えたいと言われたら

文字の位置・大きさは `cover.ts` の `calibrate(...)` にある見本（2026-11-28 竜星のPAO秋葉原ロケット無線店の画像）の座標で決めている。背景を差し替えるときは文字なしの 1200×675 を `background.png` に置く。今の `background.png` は見本画像から文字を消して作ったもので、左下に消した跡が少し残る。文字なしの元画像をもらえたら差し替える。
